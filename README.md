# Fight-The-Horde

Open `index.html` directly in a browser to play the game.

Use **WASD** to move, the mouse to aim and fire, and **E** to interact with stations. Sector 4 contains four ruined beacon stations, each with a 20 m radius. Repair one from its station menu using its listed resource costs to block biome effects and gain 1.5 HP/s regeneration, a crafting table, and four automated turrets.
